Workflow

Layout
  • User scope, configuration for all projects on the computer

  • Project scope, configuration for the current project for all users

Mode
  • Shift + Tab to change mode
  • Manual mode (default), prompts for approval before each tool call not already allowed by settings
  • Auto accept edits, automatically accepts file edits (Read/Edit/Write) without prompting, but still asks for other risky actions like Bash commands
  • Plan mode, read-only; used to research and draft a plan before any edits/actions are taken
