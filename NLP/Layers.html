Context Engineering
  • What
    • Define what should the model know and have available right now?
    • Context can contain system instructions, user request, history, retrieved documents, structured data, memory, tool definitons, too results, skills, task state, examples, output schema
    • Grounding, determines which of those to give the model based on specific, external, relevant evidence
    • Limited context window
    • Too much context can reduce quality
    • Cost and latency
  • How
    • Write context outside the immediate context so it can be reused
    • Select only the context relevant to the current step
    • Retrieve context with ranking and filtering, RAG
    • Compress context
    • Trim context
    • Each subagent uses its own context
    • Use state outside the LLM context, keep large raw data and send summary to LLM
    • Result transformation, instead of sending large queried data to LLM, select sample data from large data and send it to LLM
Harness Engineering
  • What
    • Designing environments, tools, constraints and feedback that allow coding agents to work reliably
    • Harness engineering: leveraging Codex in an agent-first world, Feb 11, 2026
      • Design environments, specify intent, and build feedback loops that allow Codex agents to do reliable work
      • Define repository structure, CI configuration, formatting rules, package manager setup, and application framework—was generated by Codex CLI using GPT‑5
      • Work depth-first: breaking down larger goals into smaller building blocks (design, code, review, test, etc), prompting the agent to construct those blocks, and using them to unlock more complex tasks
      • Humans interact with the system almost entirely through prompts: an engineer describes a task, runs the agent, and allows it to open a pull request
  • How
    • Coding Agents
      • Define agent behavior instructions in Agents.md or Claude.md
      • Implement hard capabilities and restrictions with real tools
      • Define reusable procedures in Skills
    • Application
      • Store instructions in md files and use them as system prompt
Loop Engineering

  • What
    • Design the repeated execution cycle that lets an AI agent keep working toward a goal instead of requiring the user to manually prompt it after every step
    • Agents iteratively act, observe, adjust, and continue until a user-defined goal is complete
  • How
    • OpenAI Agents SDK, Claude Agent SDK
    • Codex, Claude Code
    • LangChain, LangGraph

Ontology Engineering
  • What
    • Define what things exist in this domain, what do they mean, how are they related, and what rules/constraints apply to them?
    • Valuable when your AI has to operate across a complex domain with stable concepts and many relationships
