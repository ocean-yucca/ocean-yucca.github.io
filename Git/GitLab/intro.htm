Introduction
Access
  • Project token
    • Project -> Settings -> Access tokens
    • role: developer or above
    • scope: read_repository, write_repository
    • # clone
# git clone https_url
usrname: project_[project_id]_bot
pwd: project_token
  • Personal token
    • Profile -> Access -> Personal access tokens
    • scope: read_repository + write_repository
    • # git clone https_url
git clone https://gitlab.com/lin.chen2/cyber1.git
usrname: gitlab_usrname
pwd: personal_token
  • SSH
    • # git clone ssh_url
    Roles
  • Guest, no code access, view and comment on issues and epics
  • Planner, view code only, create and manage issues, epics, milestone, and iterations
  • Reportor, view code only, create issues and generate report
  • Security Manager, view and manage security features
  • Deverloper, push code to non-protected branches, create merge requests and run pipeline
  • Maintainer, push code, manage branches, merge request, cannot delete project
  • Owner, full control
