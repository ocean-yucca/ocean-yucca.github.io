Workflow

  1. You push code to GitLab (e.g., commit to main branch)
  2. GitLab CI/CD
    • Parses .gitlab-ci.yml
    • Triggers a pipeline
    • Assigns a job to a Docker-based runner
  3. Runner pulls the image specified in image: (e.g., python:3.11), and creates a container from that image
  4. Runner injects the project source code into the container's working directory
    • Default is /builds/[username or group_name]/[project_name]
  5. The runner runs the job’s script: commands inside the container in working directory
Script Job

# .gitlab-ci.yml
stages:
  - run

job_1:
  stage: run
  image: python:3.11
  script:
    - python s.py
  artifacts:
    paths:
      - output.txt
    expire_in: 1 week
		
# s.py
from pathlib import Path

input_path = Path("input.txt")
output_path = Path("output.txt")

# Read input file
text = input_path.read_text()

# Create output content
result = text.upper()

# Write output file
output_path.write_text(result)

print("Created output.txt successfully")
