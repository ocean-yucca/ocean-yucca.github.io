GitHub Container
1. Create a token on GitHub
Profile -> Settings -> Developer Settings -> Personal access tokens -> Tokens (classic)
Create a token with write:packages
2. Login ghcr.io
# ghcr.io is GitHub registry
# use GitHub user name and personal access token to access
# echo token | docker login ghcr.io -u [github_username] --password-stdin
echo token | docker login ghcr.io -u gcpoperationdev-cmd --password-stdin
3. Create image and Push to ghcr.io
# build amd image and arm image, and push to GitHub container
docker buildx build \
  --platform linux/amd64,linux/arm64 \
  -t ghcr.io/gcpoperationdev-cmd/count:v2 \
  --push \
  .
4. Fetch image from ghcr.io
docker pull ghcr.io/gcpoperationdev-cmd/count:v2
