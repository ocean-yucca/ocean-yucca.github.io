Built-in Authentication
Cloud SQL Auth Proxy
  • Local/Mac
    • # 1. Enable Cloud SQL Admin API in APIs & Services

# 2. Use Application Default Credentials (ADC) to use Cloud SQL Auth Proxy

gcloud auth application-default login

# 3. Download cloud-sql-proxy
curl -o cloud-sql-proxy https://storage.googleapis.com/cloud-sql-connectors/cloud-sql-proxy/v2.11.0/cloud-sql-proxy.darwin.amd64
chmod +x cloud-sql-proxy

# 4. Connect Cloud SQL instance
./cloud-sql-proxy PROJECT_ID:REGION:INSTANCE_NAME

# 5. Login Instance with username and pwd
mysql -h 127.0.0.1 -P 3306 -u user_name -p
