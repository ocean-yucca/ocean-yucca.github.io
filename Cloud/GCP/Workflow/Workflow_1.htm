Workflow
Description
  • The application does not use other Google services
Development
  • Owner (Architect)
    1. IAM
      • Grant Viewer permission to other developers
    2. GitHub
      • Create a repo
      • Add other developers as the collaborators
    3. Cloud Shell
      • Create app
      • Test on Cloud Shell
      • Push the code to the repo
  • Viewer (Developers)
    • Cloud Shell
      • Git clone the code from the repo
      • Update the code
      • Test on Cloud Shell
      • Push to the repo
Deployment
  • Owner (Architect)
    1. Cloud Run
      • Setup CI/CD
    2. Cloud Shell
      • Update app
      • Test on Cloud Shell
      • Push the code to the repo
  • Viewer (Developers)
    • Cloud Shell
      • Update the code
      • Test on Cloud Shell
      • Push to the repo
Sample Code
# app.py
import dash
from dash import html
from dash.dependencies import Input, Output
 
app = dash.Dash(__name__)
server = app.server
 
num_click = 0
 
app.layout = html.Div([
    html.Button('Click', id = 'click'),
    html.Div('0', id = 'content')
        ])
 
@app.callback(
    Output('content', 'children'),
    Input('click', 'n_clicks'))
def display_hover_data(c):
    if c:
        global num_click
        num_click += 1
        return num_click
    else:
        return 0
 
if __name__ == "__main__":
    app.run(host="0.0.0.0", port=8080, debug=True)

Comments
  • Group
    • In an organization, admin can create groups, such as editor group, developer group, grant each group with different permissions, then add principals to groups
    • Personal account cannot create groups
  • Authentication
    • When setup the Cloud Run service as require authentication, roles/run.invoker is not sufficient, may need setup IAP with https to verify IAM roles
