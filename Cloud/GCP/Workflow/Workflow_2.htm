Workflow
Description
  • The application does not use other Google services
Development
  • Owner (Architect)
    1. IAM
      • Grant Viewer permission to other developers for viewing the project
      • Grant Service Usage Consumer for using Google Cloud API & Services
    2. Cloud Storage
      • Select a bucket and grant Storage Object Admin to developers which is bucket-level permission
    3. GitHub
      • Create a repo
      • Add other developers as the collaborators
    4. Cloud Shell
      • Create app
      • Test on Cloud Shell
      • Push the code to the repo
  • Viewer (Developers)
    • Cloud Shell
      • Git clone the code from the repo
      • Update the code
      • Test on Cloud Shell
      • Push to the repo
Deployment
  • Owner (Architect)
    • IAM
      • Create a Service Account (SA) with Storage Object User permission
    • Cloud Run
      • Setup CI/CD with the created SA
        • Security -> Service Account
      • Each app on Cloud Run only can have one SA
    • Cloud Shell
      • Update app
      • Test on Cloud Shell
      • Push the code to the repo
  • Viewer (Developers)
    • Cloud Shell
      • Update the code
      • Test on Cloud Shell
      • Push to the repo
Sample Code
# app.py
from google.cloud import storage

# download data from cloud storage bucket
client = storage.Client()
bucket = client.bucket("gcpoperationbucket")
blob = bucket.blob('housing.csv')
blob.download_to_filename('housing.csv')

import dash
from dash import html, dash_table
import pandas as pd
 
# display data on a datatable
app = dash.Dash(__name__)
server = app.server

df = pd.read_csv("housing.csv")
df = df.iloc[:10,]
 
app.layout = html.Div(
    children=[
        html.H2("California Housing Data"),
        html.H4("-- updated by gcpoperationdev"),

        dash_table.DataTable(
            data=df.to_dict("records"),
            columns=[{"name": col, "id": col} for col in df.columns],

            # Optional but very useful features
            page_size=10,
            sort_action="native",
            filter_action="native",

            style_table={"overflowX": "auto"},
            style_cell={
                "textAlign": "left",
                "padding": "8px",
                "whiteSpace": "normal"
            },
        )
    ],
    style={"padding": "40px"}
)
 
if __name__ == "__main__":
    app.run(host="0.0.0.0", port=8080, debug=True)
            
# Dockerfile
FROM python:3
WORKDIR /usr/src/app
COPY . .
RUN pip install --no-cache-dir -r requirements.txt
EXPOSE 8080
CMD ["python", "./app.py"]
