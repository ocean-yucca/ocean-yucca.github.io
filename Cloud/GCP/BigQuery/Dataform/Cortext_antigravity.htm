Antigravity
Benefits
  • Standardization across developers, Antigravity can use the established patterns to create new modules more consistently for all developer
  • Reusable generation logic, useful when many tables share similar transformations
  • Repeatable build and deployment, be able to incorporate build/deploy into GitHub Actions or another CI/CD pipeline
  • Separation between configuration and implementation
  • Agent skills, provide project-specific instructions for building Cortex data products instead of relying only on your general natural-language prompt
Workflow
# download Cortex from https://github.com/GoogleCloudPlatform/cortex-framework
git clone https://github.com/GoogleCloudPlatform/cortex-framework.git
          
# start antigravity with proceeding without asking
agy --dangerously-skip-permissions
