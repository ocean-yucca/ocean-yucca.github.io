Introduction
Load Data
  • Internal table
    • Data is stored inside BigQuery
    • BigQuery fully manages storage, layout, and optimizatio
  • External table
    • Data stays in source
    • BigQuery stores metadata only
    • Queries read files in place
  • BigLake table
    • Data stays in source
    • Uses a SA connection
  • Batch load
    • Load files from source into BigQuery
    • One-time or scheduled
    • Data table is internal/native table
  • Data Transfer
    • Copies data from source into BigQuery
    • Scheduled refresh
    • Data table is internal/native table
  • Streaming
    • Data is available within seconds
    • Data table is internal/native table
  • Federated
    • Query data in place
    • No copy into BigQuery
    • Data table is external table or BigLake table

  • Pipelines

  • ML Model
