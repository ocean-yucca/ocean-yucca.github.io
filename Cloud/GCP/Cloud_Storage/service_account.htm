Google Cloud Storage
Access with Key
  • Google Cloud Side
    1. Create a Service Account
      • IAM & Admin -> Service Accounts -> Create service account
      • Permissions -> Cloud Storage -> Storage Object Admin (IAM permission)
    2. Create a Key for the Service Account
      • Open the service account created, create a json key and save
    3. Enable the Cloud Storage API in APIs & Services
  • App Side - Access with Requests
    • pip install google-cloud-storage
            
    from google.oauth2.service_account import Credentials
from google.cloud import storage
import json

# load credentials from key
with open("key.json", "r") as f:
    key_data = json.load(f)

credentials = Credentials.from_service_account_info(key_data)
client = storage.Client(credentials=credentials)
            
    # list blobs in bucket
bucket = client.bucket("app-operations-bucket")
for blob in bucket.list_blobs():
    print(blob.name)
		
    # list blobs begin with a prefix
bucket = client.bucket("app-operations-bucket")
blobs = bucket.list_blobs(prefix="data")
for blob in blobs:
    print(blob.name)
            
    # list blobs in a directory
# delimiter="/", restrict the results to only the files in the given folder
bucket = client.bucket("app-operations-bucket")
blobs = bucket.list_blobs(prefix="data/", delimiter="/")
for blob in blobs:
    print(blob.name)
            
    # download file
bucket = client.bucket("app-operations-bucket")
blob = bucket.blob('data/housing.csv') # source on Cloud Storage
blob.download_to_filename('housing.csv') # destination in local
            
    # upload file
bucket = client.bucket("app-operations-bucket")
blob = bucket.blob('data_2/housing.csv') # destination on Cloud Storage

blob.upload_from_filename('housing.csv') # source in local
            
    # delete file
bucket = client.bucket("app-operations-bucket")
blob = bucket.blob('data_2/housing.csv') # blob on Cloud Storage
blob.delete()
            
    # rename or move file
bucket = client.bucket("app-operations-bucket")
blob = bucket.blob('data/housing.csv')

new_blob = bucket.copy_blob(blob, bucket, 'data_2/housing.csv')
blob.delete()
    Access with Token Creator
  • Google Cloud Side
    1. Create a Service Account (SA)
      • IAM & Admin -> Service Accounts -> Create service account
    2. Enable the Cloud Storage API in APIs & Services
    3. Grant SA the access to Cloud Storage
      • SA -> Permissions -> Manage Access -> Storage Object Admin (IAM permission)
    4. Grant a user to impersonate the SA
      • SA -> Principals with access -> select a user -> Add Service Account Token Creator
  • App Side - Access with Requests
  • Creates credential file for the user
    • gcloud auth application-default login

# create ~/.config/gcloud/application_default_credentials.json
            
    from google.auth import default
from google.auth.impersonated_credentials import Credentials as ImpersonatedCredentials
from google.cloud import storage

TARGET_SA = "storage-app@spheric-gasket-476418-h5.iam.gserviceaccount.com" # SA email
BUCKET_NAME = "app-operations-bucket" # bucket name

SCOPES = ["https://www.googleapis.com/auth/devstorage.read_write"]
source_credentials, project_id = default() # get user credentials from ~/.config/gcloud/application_default_credentials.json

target_credentials = ImpersonatedCredentials(
        source_credentials=source_credentials,
        target_principal=TARGET_SA,
        target_scopes=SCOPES,
        lifetime=3600,
    )

client = storage.Client(credentials=target_credentials, project=project_id)

bucket = client.bucket(BUCKET_NAME)

print("Files in bucket:")
for blob in bucket.list_blobs():
    print(" -", blob.name)
