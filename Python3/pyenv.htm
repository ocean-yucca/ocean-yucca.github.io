pyenv
List Python Versions
# list available Python versions
pyenv install --list
			
# list installed versions
pyenv versions
Install Python Versions
# install python version
pyenv install 3.11.7
Global
# change python version
# default python version is system
# pyenv global select a python version for all directories
pyenv global 3.11.7
Local
# select a python version for the current directory
# create .python-version which specify the python version for the current directory
pyenv local 3.11.7
