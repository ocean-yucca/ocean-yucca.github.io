uv
Environments
  • Activated virtual environment
    • Created explicitly by user
    • Lives at a known path (.venv/)
    • Controlled by shell
    • Can manually installs
    • Used implicitly by python, pip, pytest
      • python → .venv/bin/python
      • pip → .venv/bin/pip, python -m ensurepip --upgrade
      • PATH is rewritten to prioritize .venv/bin
  • Resolved environment
    • Created and controlled by uv
    • Defined by project metadata
    • Shell activation is ignored
    • Used only when run uv run / uv pip
    • uv venv
    # create a virtual environment
uv venv # default name .venv

# create a virtual environment with specific name
# uv venv [venv_name]
uv venv .myvenv

# create a virtual environment with specific python distribution
uv venv --python 3.11

# activate virtual environment
# source [venv_name]/bin/activate
source .venv/bin/activate

# deactivate virtual environment
deactivate

# remove virtual environment
# rm -rf .[venv_name]
rm -rf .venv
    uv pip
    • Resolves the project environment, reads pyproject.toml and enforces requires-python
    • Selects or installs the correct Python
    • Creates / reuses an isolated environment
    • Runs pip inside that environment
    # check which pip is used
pip --version

pip # unreliable, may use pip in base even in activate environment

# python -m ensurepip --upgrade
python -m pip # reliable for the active interpreter, use the pip in activate environment

uv pip # pip in uv-resolved environment
    uv run
    • Resolves the project environment, reads pyproject.toml and enforces requires-python
    • Selects or installs the correct Python
    • Creates / reuses an isolated environment
    • Exposes packages declared in the project dependencies
    • run a command inside the resolved project environment
    # implement python script
uv run python script.py # use python in the current virtual environment
python script.py # in special case, it may use system/conda/pyenv python rather than python in the current virtual environment

# test
uv run pytest
    uv version
    # read and display package name and version from pyproject.toml
uv version
